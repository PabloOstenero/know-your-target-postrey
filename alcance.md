# Alcance del proyecto

## 1. Programa
Nombre: Airbnb
Plataforma: HackerOne
URL oficial: https://hackerone.com/airbnb
Fecha de consulta: 2026-10-28

## 2. Objetivo
Organización: Airbnb
Dominio principal: airbnb.com

## 3. Activos dentro del alcance
- *.airbnb.com, incluidos los sitios localizados (por ejemplo es.airbnb.com, it.airbnb.com). La política lo clasifica como «impacto más alto».

## 4. Activos fuera del alcance
- Todo dominio que no sea *.airbnb.com. Aunque el programa incluya otros dominios (*.airbnb.org, *.muscache.com, HotelTonight, etc.), en este proyecto los dejo fuera para acotar el trabajo.
- Activos de terceros: la política solo cubre componentes bajo control de Airbnb.
- Aplicaciones móviles (iOS y Android): no son objetivo del proyecto.

## 5. Reglas que afectan al proyecto
- No crear cuentas de forma masiva
- No hacer fuerza bruta, ni siquiera para probar límites
- Ingeniería social prohibida
- Evitar violar la privacidad o degradar el servicio
- Interactuar solo con cuentas propias
- Los activos de terceros no están cubiertos
